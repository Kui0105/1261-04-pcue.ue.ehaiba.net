- mock 机制澄清：所有 mock 开关均为严格 `import.meta.env.VITE_USE_MOCK === 'true'`，仅 `.env.development` 设 `true`；`vite build` 默认 production 模式读 `.env.production`（未定义→undefined），mock 分支被 tree-shaking 整段删除，**生产构建本身不可能走 mock**。若线上仍见 mock，根因是部署方式：服务器实际跑 `npm run dev`（读 development env）或线上是旧 dev 构建未重建。v1.6.11 在 `.env.production` 显式加 `VITE_USE_MOCK = false` 双保险（commit `280a5b8`）。正式部署规范：必须用 `npm run build` 产出 dist 后做静态托管，禁止在生产机跑 `npm run dev`。
